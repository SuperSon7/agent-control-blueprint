# 확정한 이슈 구현

현재 이슈의 mode, 목표, 인수 조건, 변경 범위와 프로젝트 지침을 확인한다. 명시된 portfolio 모드는 이 스킬로 delivery로 변경하지 않는다. 아직 모드가 없으면 사용자가 선택한 기본값을 기록한다.

기존 코드·기준 예제·관련 테스트부터 읽고 확정 범위의 결과를 구현한다. 새 기능·의존성·구조 변경이 필요하면 영향과 다음 필요한 결정을 드러내고 범위를 임의로 늘리지 않는다.

이미 승인된 범위의 조사·수정·검증은 이어서 수행한다. 모드별 추가 학습 질문을 만들지 않는다. 비용·검사·권한·배포 게이트는 그대로 따른다.

적절한 실제 검사를 실행하고 실패하면 기존 예산 안에서 수정한다. 검사를 제거하거나 모델의 주장으로 통과시키지 않는다. 중단 시 단계·세션·커밋·남은 문제를 남기고 재개할 때 재확인한다.

완료에는 변경 내용, 실제 검증과 미검증 사항, 다음 필요한 행동을 짧게 남긴다. 게시·병합·배포는 현재 사용자의 승인 범위와 등록된 실행기에 따른다. 스킬 선택 자체가 외부 작업 권한은 아니다.
