# 학습 근거와 사례 기록

기존 프로젝트 형식이 있으면 따른다. 없으면 docs/learning/<issue-id>/에 계획·결정·실험·해석·설명·사례를 남긴다.

각 기록에는 작업·명세·모드 버전, 작성 주체, 기준 커밋, 자료 출처를 연결한다. 소유자 답은 실제 채팅 원문이나 소유자가 직접 작성하고 확인한 문서에 연결한다. AI 초안은 AI 지원으로 표시한다.

사례는 문제, 제약, 비교한 선택지, 소유자가 선택한 이유, 실제 결과, 한계로 작성한다. 실험에는 조건, 실패 주입 위치, 실행 명령 또는 실행 ID, 실제 결과를 남긴다. 원문에 없는 성능 수치·성공률·본인 기여를 만들지 않는다.

체크포인트가 없거나 실제 실험이 없으면 준비됨·미실행·해석 대기로 표시한다. 파일 존재만으로 완료하지 않는다. 비밀 값과 운영 원본 로그는 공개 사례에 포함하지 않고 제거된 요약과 보호 저장소 참조를 사용한다.
